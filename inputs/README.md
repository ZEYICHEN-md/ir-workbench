# 当期原件

这里只放**这一期用完就可以换掉**的材料：中金周报、STR、研报、财报、访谈。
长期底稿、情报库、权威 Model 不在这里，见 `data/`。

拖进对话框也可以，Agent 会代为归位。各子文件夹里的 README 会随工作台一起分发；PDF 和大 Excel 原件默认不进 Git。

| 子文件夹 | 收什么 |
|---|---|
| `industry-data/` | 中金旅游周报、STR 表 |
| `news-digest/` | 写精选用的剪报、公众号导出 |
| `sellside-research/` | 卖方研报 PDF |
| `peers-model/` | 一家公司当次的财报 / 电话会 PDF |
| `expert-calls/` | 专家访谈 PDF |
| `intel-quarterly/` | 按公司、按财季收的披露材料包 |
| `aviation-monthly/` | 若要留底的民航局 / 三大航公告 PDF |

股东名册的 Capital IQ 底表放电脑「下载」，不要放这里。
成品去 `outputs/`。说明见 [docs/MAP.md](../docs/MAP.md)。
