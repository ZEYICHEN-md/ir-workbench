# 源质量门槛：一切「非旗舰源」命中都要过

> **迁移说明（2026-08-25）**：从旧仓 `travel-weekly-report/references/decisions/ADR-004-source-whitelist.md`
> 与 `data-sources.md` 源质量节搬入。**第一次迁移整条漏了。**
>
> 漏了为什么严重：SKILL 要求每期用 exa / tavily 跑补充检索，那必然捞回
> `travelandtourworld.com` 这类聚合农场稿和「XX 旅游公司 TOP10」这类 SEO 榜单。
> 没有门槛，它们会直接落进**唯一的对外交付物**。

## 门槛

**旗舰源免检**：`ir news recall` 枚举出来的 Skift 与 36氪 `in_scope` 条目、PhocusWire。

**其余一律要过门槛**——凡搜索捞回的稿（中文 exa/tavily、英文 exa、B 类放开域名扫回的），
其**正文、数字、链接必须落到可信源**上。落不到：

| 类别 | 处理 |
|---|---|
| B 类外部冲击（中断/罢工/签证/地缘） | **降级为一句话提及**，不展开、不进新闻来源表 |
| 其他所有类 | **不收** |

内容农场与低质源**只能当「线索发现」**——知道有这么件事，然后必须换成可信源再写。

## 可信源怎么判

**正面清单（免检加速器）+ 判定原则（清单外用）。**

正面清单**不是闭集**：不在清单上不等于不可信。这条限定是为了避免误杀 Globe and Mail
这类没列进来的正规大报。

**英文**：Reuters、AP、Bloomberg、BBC、Guardian、Euronews、FT、WSJ、NYT、CNBC、
Skift、PhocusWire、TravelWeekly、官方（各国民航局 / 边境机构 / 航司官网 / 交易所）。

**中文**：环球旅讯、财新、第一财经、界面、澎湃、36氪、晚点 LatePost、虎嗅、
新浪财经 / 网易财经 / 腾讯新闻（**正规媒体端，不是自媒体号**）、
官方（市监总局 / 民航局 / 文旅部 / 交通运输部 / 网信办 / 国家移民管理局）。

**判定原则（清单外的源用这条）**：原发的正规新闻或财经媒体、官方机构 = 可信可用；
聚合农场 / SEO 榜单站 / 自媒体搬运号 / UGC = 不可信，只当线索。

**排除特征（命中任一即判不可信）**：

1. 已知聚合农场 / SEO 站（`thetraveler.org`、`travelandtourworld.com`、
   `travelandtannins.com`、`dctravelservice.com`…）
2. 榜单体标题（「TOP10」「排名」「推荐」「靠谱」）
3. 转载搬运（无署名记者、无原发机构）
4. UGC 平台（贴吧、股吧、知乎回答、小红书、短视频）

正面清单是**活清单**，随实践增补，不一次定死。

## 为什么这样够用

B 类真正的大事件（罢工 / 机场关闭 / 签证新政 / 地缘冲突）主流媒体几乎必报——
要求「必须落到可信源」基本不会漏掉真大事件，反而天然滤掉农场的夸大与杜撰。

实测：EES 边检排队、海湾空域冲突致航班大面积取消，两件都是农场先命中，
但 Guardian / BBC / Euronews / Reuters 都有可信版本，交叉验证属实。

**残留风险**：某件真事只有农场报 → 按规则降级或不收。接受——这种大概率本来也不够格
进 IR 的对外材料。

## 摘要纪律（防脑补）

只写**抽取到的正文或 Skift Take 支持得住**的内容。

碰上付费墙、只拿到标题加短预览时，把摘要**写短、写稳**（宁可 40 字点到为止），
**不要凭标题脑补出没有依据的分析或数字**。拿不准的判断用「或 / 据报道」限定，
不要当既成事实。引用的原文句子必须真实出现过，抓不到就省略，不自造。

> Skift 有 Pro 付费墙。tavily advanced 抽取与 exa fetch 都只能拿到
> 「Skift Take」摘要加部分正文段——够写中文摘要，但**不够支撑细节数字**。
> 这就是上面那条纪律的直接来源。
