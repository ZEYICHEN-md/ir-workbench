# 港股市场数据

内部按需查询能力，不进入新闻精选，不对外发布。唯一入口是 `ir hk-market ...`。

## 路由

- 「港股行情 / 恒指 / 恒生科技 / 携程港股这周」→ `market`
- 「南向持股 / 港股通持股」→ `southbound`
- 「港美成交占比 / 55% / 转主要上市」→ `volume-ratio`

Agent 代跑命令并用人话汇报，不把命令交给使用者。

## 三条口径

### 行情

周涨跌为本 ISO 周最后交易日收盘对上个 ISO 周最后交易日收盘。
指数 `amount` 来自新浪指数日线，是指数成分股成交额，不是港股全市场成交额。
携程成交额优先取 akshare；回退 yfinance 时是 `Volume × Close` 近似值，汇报必须说明。

### 南向持股

来源为港交所 CCASS「沪港通及深港通持股纪录按日查询」：
https://www3.hkexnews.hk/sdw/search/mutualmarket_c.aspx?t=hk

查询目标月全部工作日，节假日按实际披露日去重；回退到上月的数据必须排除。汇报标明实际持股日期，
不能把请求日期写成数据日期。

### 港美成交占比

- 港股成交额优先 akshare 港交所口径，失败才回退 `Volume × Close`。
- 美股无直接成交额字段，用 `Volume × (High + Low) / 2` 近似 VWAP 成交额。
- 美元成交额按命令中明确列出的 USD/HKD 汇率换算。
- 港美市场各自聚合全部交易日后再按月合并，不要求同日对齐。
- **港交所 55% 测试只看最近完整财年 FY。**L12M、最近季度、最新月只看趋势，
  绝不能据此写「已达到监管阈值」。
- 达到 55% 应中立表述为可能触发主要交易迁港与后续主要/双重主要上市安排，
  不使用「红线」「预警」等预设负面的措辞。
- 本结果是估算；正式认定以港交所通知为准。

默认股票池：携程、华住、网易、百度。纯港股公司没有美股腿，不适用该计算。

## 产出与留痕

结果写入 `outputs/hk-market/<实际查询日>/`；`runs/hk-market/<实际查询日>/manifest.json`
记录口径与输出 SHA-256。三类查询彼此独立，不要求同一天全部执行。

外部数据部分失败必须返回 `partial` 并逐项列出；全失败返回 `failed`，不得用旧缓存包装成最新结果。
