# 卖方研报摘读

轻量内部查询能力。依据 ADR 0004：不建持久索引、不进竞对情报库、不进入新闻精选。

## 流程

1. 用户提供 PDF；原件可放 `inputs/sellside-research/`，真实研报受 `.gitignore` 保护。
2. Agent 代跑 `ir sellside extract --file <PDF>`，得到带页码的抽取底稿。
3. 同时查看原 PDF：抽取为空的图表页不能跳过，关键表格须直接核对。
4. 按用户问题摘读；没有特定问题时用下方默认结构。

## 默认摘读结构

- **报告信息**：机构、标题、日期、覆盖公司/行业。
- **一句话结论**：这是分析师观点，不写成已发生事实。
- **已发生事实/公司披露**：事实、数据期、单位、原文页码。
- **分析师判断与预测**：明确写「报告认为/预计」，保留预测期、假设与页码。
- **估值与盈利预测变化**：旧值、新值、变化幅度、币种、口径、页码。
- **值得继续核对的问题**：与公司披露冲突、来源链较远、口径不清或图表无法可靠抽取的项。

每个关键数字与结论用 `PDF 第 N 页` 标出处。若 PDF 页码与印刷页码不同，优先写 PDF 查看器页码，
必要时并列注明报告内页码。

## 边界

- 研报观点和预测不是公司事实，不得改写成确定口径。
- 不外传研报原文、截图或大段摘录；输出只供内部查询。
- 不因为研报提到某公司就自动沉淀到情报库。若未来需要跨季度索引，必须新 ADR 推翻 0004。
- 扫描件或整份无文本时返回 `blocked`，先 OCR；不能用空抽取假装完成。
- 本域无周期键，也不产生 `runs/` manifest；输出文件名只用于当次摘读，不构成长期档案。
