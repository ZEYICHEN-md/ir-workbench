# ADR 0001 — 指标底稿以 Excel 为唯一真源，指标快照可全量重建

- 状态：**Accepted**（2026-08-22 确认）
- 日期：2026-08-22
- 取代：`database_matain/docs/adr/0002-canonical-json-source-of-truth.md`

## 背景

`database_matain` 现行规则把 `travel.json`（canonical JSON）定为指标权威，Excel 定为「数据入口」，并明确写「入口不等于权威源」。入口合并规则 B1 为：Excel 非空值覆盖快照，**Excel 为空则保留快照已有值**。

实际使用中，人只在 Excel 上编辑；航空月度 pipeline 也只写 Excel。「权威在 JSON、但你只能改 Excel」这条绕弯的语义，与使用者的心智模型不一致。

现行规则带来四个已确认的问题：

1. **撤回死锁。** 把 Excel 某格清空（例如发现数据来源不可靠要撤回），B1 会保留快照旧值，看板继续显示已撤回的数字。想真撤回只能手改 JSON，但规则又禁止手改 JSON。
2. **静默分叉。** 只要 Excel 对应格为空，快照里与 Excel 不一致的值可以永久存在，且无任何机制会提示。
3. **静默失败。** Excel 结构变化（新年度块、列位移）导致 parser 读出大量 `None` 时，快照保留旧值，看板照常显示，故障可能数周不被发现。
4. **语义与行为不一致。** 这类「技术上合法、业务上未必成立」的错误最难被 code review 发现，也最难移交给非技术接手人。

## 决策

**指标底稿（Excel）是国内行业指标的唯一真源。指标快照（`travel.json`）是它的机器投影，可随时全量重建，不接受手改。**

- Excel 单元格为空 = 该数据不存在。重建后快照对应位置为空，下游不再显示。
- 任何数值修正一律回 Excel 改，不改快照。
- 洞察底稿（`travel-insights.json`）是独立真源，不受指标重建影响。
- 航空月度 pipeline 写入 Excel 后，其成功判据是 Excel 目标格正确，而非快照状态。

### 配套门禁（本决策的必要条件）

重建前先与现有快照 diff，并按以下规则处置：

| 情况 | 行为 |
|------|------|
| 仅新增 / 数值变更 | 直接写入 |
| 出现清空（原有值 → 空） | 列出被清空的时间标签与指标，等人确认 |
| 清空格数超过阈值 | `blocked`，报告疑似 parser 或 Excel 结构问题，不写入 |
| 底稿读取抛错 | `blocked`，不写入，保留上一版快照 |

没有这道门禁则本决策不成立——问题 3 会从「静默错误」变成「静默事故」。

## 代价评估（已核实）

改动量小，因为：

1. 快照目前只装 2026 一年（32 周 + 12 月 + Q1/Q2），**无历史数据会被重建波及**。
2. 洞察已是独立文件，重建不触及。
3. parser 覆盖面与快照形状一一对应（周度 7 序列、月度 9 序列、季度 Q1–Q4），不存在「快照有、Excel 读不出」的指标字段。
4. 唯一例外是 `meta.dataSource` 与 `meta.compareBase` 两个手写字段，不在 Excel 中，需另行安置。

实施 = 改 `merge_b1` 一个函数 + 加 diff 门禁 + 安置两个 meta 字段。

### 实施后的两处修正（2026-08-22）

**1. 两个 meta 字段放代码常量，不放本机配置。**
本文原写「迁入配置」，实施时改为 `modules/industry_data/snapshot.py` 的 `SNAPSHOT_META` 常量。
理由：本机配置在 `.ir-workbench/`（Git 忽略），而这两个字段描述工作簿的**固定口径**、
不是机器相关设置——放进被忽略的配置会在新机器上丢失。

**2. diff 门禁的比例规则要有最小样本量。**
初版「某序列清空 > 30% 即 blocked」在短序列上误伤（1/1 就是 100%），被回归测试抓到。
现规则：比例判定仅在该序列原有非空格数 ≥ 5 时生效，短序列只由数量规则管。

## 后果

**好的：**
- 语义可一句话讲完：「那张 Excel 就是我们的数据，改它就行」。这是非技术接手人能长期持有的心智模型。
- 撤回可行；快照与底稿的分叉在结构上不可能长期存在。
- parser 故障从静默变为显式拦截。

**实施当天就验证了最后一条。**全量重建立刻暴露一个**既有的静默 parser 缺陷**：
底稿月份行写作 `7月 (preliminary)`，旧实现用 `^\d{1,2}月$` 严格匹配，在 7 月处提前
终止，月度只读到 6 个月。这个缺陷此前一直被「空值保留旧值」掩盖——快照里那 12 个月
是冷启动时从 `data.js` 带来的，看板照常显示，无人知晓。

修正后重建，与旧快照的差异恰好三处，**全部是旧管道漏掉的真实数据**，没有任何丢失：

| 位置 | 旧 | 新 |
|---|---|---|
| `monthly.hotelRevPAR[6]`（7月） | `null` | `-0.05` |
| `quarterly.q2.hotelOccupancy` | 缺字段 | `-0.008333333333333333` |
| `quarterly.q2.hotelADR` | 缺字段 | `0.028999999999999998` |

**要接受的：**
- Excel 临时缺格会被如实反映为缺失，容错由 diff 门禁而非「保留旧值」提供。
- 需要一条硬纪律：**任何人任何时候都不手改 `travel.json`。**
- Excel 成为单点：它损坏或丢失即指标丢失，需纳入备份策略。
