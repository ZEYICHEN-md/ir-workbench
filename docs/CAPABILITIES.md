# IR 工作台 — 功能清单

> 面向部门同事与接手人：工作台能做什么、怎么开口、产出在哪。
> 你只需要说自然语言，Agent 负责其余部分。
>
> **迁移期提示（2026-09-01）**：目前 **5/8** 个域已迁入新架构。
> `industry-data`、`aviation-monthly`、`news-digest` 与 `competitor-intel` 已完成真实业务验收；
> `expert-calls` 已完成代码迁移、线上版式回读、回归测试和 7 篇真实访谈候选排序只读验证，待人工选择后做首次发布验收。
> `hk-market`、`sellside-research`、`peers-appendix` 尚未迁入，暂不能从统一入口运行。
> 实时进度以 `docs/MIGRATION.md` 为准。

## 怎么用

打开工作台文件夹（Kiro、Cursor 或 Claude Code 均可），对 Agent 说话。不需要记命令，不需要开终端。

不确定能做什么的时候，问一句「**工作台现在能做什么 / 什么状态**」。

## 一、对外交付

### 旅行行业新闻精选（每周）

发给部门外的人看的唯一产物。覆盖 OTA 与旅游行业动态，含本周概览、逐条要闻（带具体数字与竞对含义）、以及完整的来源表（媒体 / 日期 / URL）。

- **怎么开口**：「做 2026年8月第3周的新闻精选」；只有新闻时说「更新新闻周报」
- **产出**：markdown / HTML / PDF 三件
- **附带**：写完自动沉淀进竞对情报库，不需要额外操作
- **纪律**：不写任何携程自己的动作与表述

## 二、内部数据维护

### 国内行业数据与看板（每周 / 每月）

以那张**国内行业数据 Excel** 为唯一编辑面。酒店 STR 与周度航空由人手填，月度航空由自动化写入。同步后逐格判断周度/月度/季度哪些真的变了，只为变动层自动出洞察草稿；你审完中文说「写入上线」后，系统再入库、英译并发布看板。飞书多维表目前不在默认链路，需要时单独说。

- **怎么开口**：「更新国内行业数据」；Agent 不会再多问要不要刷新洞察，而是直接给对应层的草稿
- **产出**：中文洞察审查稿 → 确认后中英文洞察与 datamax.fun 看板
- **硬门禁**：确认清空、洞察入库与对外上线都须明确措辞；飞书仅在明确要求时写入

### 航空月度数据自动写入（每月）

抓民航局月报与三大航公告，校验后写入 Excel 的四个目标格。省掉手工抄数与算同比。

- **怎么开口**：「更新 7 月航空官方数据」
- **产出**：Excel 目标格 + manifest（含每个输入格的来源批注）
- **硬门禁**：先 dry-run，确认后才正式写入

## 三、内部查询

这三项只在你想了解时调用，不产出对外文档。

### 港股市场数据

行情、南向持股、港美成交额占比（55% 监管阈值跟踪，只看最近完整财年 FY）。

- **怎么开口**：「查一下港美成交占比现在多少」「南向持股这周怎么样」

### 竞对情报检索

按公司或按主题查 peers 动态。**按公司**看某家这季度干了什么；**按主题**横切看所有 peers 在某件事上分别做了什么、怎么说的。

- **怎么开口**：「Booking 这季度在 B2B 上做了什么」「所有 peers 在 AI 入口这件事上的动作」「Expedia 电话会怎么讲 AEO」
- **料从哪来**：三条通道——每周新闻（自动沉淀）、财报季电话会口径、专家访谈
- **建档公司**：ABNB / BKNG / EXPE / TCOM / 美团 / 同程 / 飞猪 / 豆包·抖音
- **可检索但不建档**：MMYT / TRIP（Tripadvisor）/ 途牛 / 华住 / 亚朵 / 万豪 / 希尔顿 / IHG，以及其他桶

### 卖方研报摘读

把研报 PDF 放进来，Agent 帮读帮摘。轻量能力，不建持久档案。

- **怎么开口**：把 PDF 拖进对话，说「帮我摘一下这份 UBS 酒店 first read」

## 三点五、专家访谈精选

把一批专家访谈 PDF（飞书链接或本地文件）交给 Agent，系统先生成一份**供人选择的候选排序报告**：逐篇说明大致讲什么、最有价值的数据、具有高参考意义的行业事实与洞察、证据局限，并按透明的五维评分给出 A/B/C 建议档位。排序不替人决定；你选中后，系统才生成与目标 Wiki 现有三条完全一致的 revision 1680 callout 草稿。用户明确确认后才写入飞书；每条写后都会回读并用新 block id 串行插入，避免重复和逆序。

- **怎么开口**：「看看这些访谈哪些值得写」「做一份 Expert Call 候选排序」或「更新 Expert Call，以下是访谈……」
- **排序内容**：一句话概述、关键数据及原话页码、高参考意义的事实/洞察、局限、五维评分理由和 A/B/C 档
- **相关范围**：携程经营、中国及跨境需求、全球 OTA 竞争、AI 旅行分发；B2B 不单独构成收录理由
- **硬门槛**：直接 IR 信息增量和至少 4 个锚定数字缺一不可；缺原话或页码位置会阻断
- **产出**：候选排序 → 人工选择 → callout 草稿 → 明确确认后飞书权威稿 → 内部情报库草稿
- **情报入库**：不会自动提交；表述条目必须保留原话与 `PDF 文件名 + 页码/位置`，另经确认后入库
- **敏感度**：真实 PDF/TXT 不进 Git；专家访谈通道条目一律 `internal`

## 四、季度工作

### Peers 业绩总结与 Appendix

Global OTA 与酒店集团发财报后的跟踪研究，最终产出季度 Appendix 活文档（Word）。自动化只做机械劳动——取数、建表、贴图、格式对齐、门禁检查；**写什么和怎么归因仍由你判断**。

- **怎么开口**：「BKNG 出财报了，做业绩总结」「更新 26Q3 Appendix 的 Expedia 段」
- **产出**：业绩总结 docx、对比表、图表、Appendix 活文档
- **配合情报库**：写「战略更新」段时先查情报库，省掉回溯采集

## 五、平台能力

| 能力 | 怎么开口 | 作用 |
|---|---|---|
| 环境自检 | 「做一次环境检查」 | 首次安装、报错时先跑这个 |
| 当前状态 | 「现在什么状态」 | 各域分别报告进度与卡在哪 |
| 更新数据文件 | 「换一份新的国内行业数据」 | 飞书群里收到新 Excel 后用 |
| 更新工作台 | 「更新一下工作台」 | 拉取维护人发布的新版本 |

## 不在工作台范围内

- **五部分旅行行业周报**：已停用，不再产出。行业数据看看板，港股问内部查询。
- 自动对外发布：任何发布（飞书、对外分享）都要你明确说了才做。
- 自动决定数据口径：来源冲突时列出数值、口径、来源和日期，等你确认。
- 替你做业务判断：写什么、怎么归因、采用哪个口径，都由你决定。
