# 数据引用与取数溯源

跨域约定。任何涉及**引用数据、从 Excel / PDF / 网页取数**的工作都适用。

## 1. 数据冲突必须提前说明，不许悄悄选一个

同一指标出现**多来源、口径不一致、或数值互相矛盾**时（官方数据 vs 第三方测算、不同报告给出不同数字、口径不同如「航班量 vs 客运量」），**先停下来说明冲突**：列出各来源的数值、口径差异、时效，给出建议选项，等用户确认后再采用。

## 2. 每个数都要能被一眼定位并核对

| 来源 | 必须标注 |
|---|---|
| **Excel** | 文件名 + **工作表名** + **单元格**（列字母+行号，如 `E308`）；区域给范围（`E308:AI308`）。必要时附表头含义（「E 列 = Mainland China 的 OCC 当前年度」） |
| **PDF** | 文件名 + **页码** + **哪张表 / 哪一行**（「第 2 页『主要生产指标』表『国内航线 万人』行」） |
| **网页** | 页面标题 + URL + 具体位置（第几段 / 哪张表） |
| **电话会 / 财报口径** | 公司 + 期次 + 原话引用 + 位置（页码或时间戳） |

呈现方式：在结论旁附一个「取数明细 / 溯源」小表：`指标 | 数值 | 来源(文件·sheet/页·行列)`。

**目的**：用户要能拿着这个出处回原始文件逐个核对，确认没取错行、列、口径。

## 3. 缺失就标缺失

取不到的标「数据缺失」，**绝不编造，也不能含糊带过出处**。部分成功要显式返回 `partial` 并说明缺什么。

## 各域的落地形态

| 域 | 溯源怎么体现 |
|---|---|
| `news-digest` | 每条附中英标题 + 媒体 + 日期 + URL 表 |
| `industry-data` | 快照 `meta.sourceExcel` 记底稿文件名，`meta.dataUpdate` 记数据截至日；读表列位契约见 `modules/industry_data/SKILL.md` |
| `aviation-monthly` | 每个官方输入格加批注：`Source: [公告标题], [日期], PDF第N页「表名」表「行名」行, [URL]`；manifest 记输入 SHA-256 |
| `competitor-intel` | 每条 entry 必须有来源 + 日期；表述类条目存原话引用 + 位置指针 |
| `peers-appendix` | 数字须来自 filings 或 transcripts；broker 仅交叉验证 |

## 系统层面的保障

`runs/<域>/<周期>/manifest.json` 记录本次运行的**输入与输出 SHA-256**。它回答的是「这个结果是由哪几份文件产生的」——与上面的单元格级溯源互补，不能互相替代。
